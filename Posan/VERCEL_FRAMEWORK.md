# Quick Answer: Vercel Framework Selection

## When Vercel Asks "What Framework?"

Select: **`Vite`** or **`Other`**

---

## Configuration Details:

| Setting | Value |
|---------|-------|
| **Framework** | `Vite` |
| **Build Command** | `npm run build` |
| **Output Directory** | `frontend/dist` |
| **Install Command** | `npm install` |
| **Root Directory** | `./` (leave as root) |

---

## Your Stack:

✅ **Frontend**: React 18 + Vite 5  
✅ **Backend**: FastAPI (Python) as Serverless Functions  
✅ **Database**: PostgreSQL  
✅ **Deployment**: Both on Vercel (monorepo)

---

## Ready to Deploy!

```bash
# Install Vercel CLI
npm install -g vercel

# Deploy
vercel
```
